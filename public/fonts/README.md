Folder ini untuk file font DaFont opsional.

Salin file Bebas-Regular.ttf, Roboto-Regular.ttf, Roboto-Medium.ttf, dan Roboto-Bold.ttf ke folder ini. Langkah lengkap ada di `FONT-INSTALLATION.md` pada folder utama.

Jika folder ini belum berisi file .ttf, website tetap menggunakan font fallback dan tetap dapat dijalankan.
